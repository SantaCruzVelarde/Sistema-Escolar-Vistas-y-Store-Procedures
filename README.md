# Sistema Escolar - Vistas y Store Procedures

Proyecto realizado para desarrollar un sistema escolar conectado a una base de datos.

Inicialmente se implementaron operaciones básicas de consulta y modificación de información mediante SELECT, INSERT, UPDATE y DELETE. Posteriormente, estas operaciones fueron reemplazadas y organizadas mediante Vistas y Store Procedures con parámetros.

**Tecnologías utilizadas**
C#

SQL Server Management

SQL

**Funcionamiento**

El sistema permite trabajar con la información almacenada en la base de datos mediante diferentes operaciones. Las Vistas permiten consultar información específica, mientras que los Store Procedures permiten ejecutar operaciones previamente definidas.

**Configuración**

Es necesario contar con el sistema gestor de base de datos utilizado en el proyecto y ejecutar los scripts correspondientes para crear la base de datos y sus componentes.
